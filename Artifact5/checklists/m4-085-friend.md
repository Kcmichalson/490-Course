# Co-op test (0.8.5): sheet for the second player

Thanks for helping again. This is a free, unofficial fan mod for XCOM 2:
War of the Chosen; it isn't made or endorsed by Firaxis or 2K. Nothing here
edits a game file.

If something looks different from this sheet, tell the host what you see;
that's useful, not a mistake.

## Before the day (about 5 minutes)
1. Replace the old mod: delete `Mods\X2TacticalCoop`, then unzip the host's
   new zip into `XCOM 2\XCom2-WarOfTheChosen\XComGame\Mods\`.
2. Same DLC and mods as last time; launch without `-allowConsole`.
3. The main menu's bottom row should read **CO-OP (v0.8.5)**. If it shows
   another version, tell the host.

## On the day
4. **New:** start the game and **wait on the main menu. Don't click
   CO-OP.** Just accept the host's Steam invite (the notification, or
   Shift+Tab, then the chat). The mission should load by itself.
   - If a lobby or a message box appears instead, take a screenshot and
     tell the host the words.
5. Play as before: you control the soldiers the host gives you; **CO-OP:
   END TURN (READY)** tells the host you're done.
6. **Things to tell the host about:**
   - **A greyed-out enemy** in the target bar that you can't select: say
     which soldier, take a screenshot if you can, and click it again after
     2 seconds.
   - **When the host hacks something:** whether the hack screen closes and
     you can carry on (wait 30 seconds before calling it stuck).
   - **Alien turns:** whether they look sped up, and whether your screen
     still falls clearly behind the host's.
   - Once, during an alien turn: Esc, Options. Is **Zip Mode** set the way
     you normally have it? Back out without changing anything.
7. **When the host asks** (from turn 5): click the **Co-op icon** (top
   right), then **FIXES**, and untick **Camera: follow moves (override)**.
8. **After each mission** you return to the main menu. **Stay there and
   don't click anything** until the host's invite comes; accept it. Don't quit the game between missions if you can avoid it.
9. Only if the host asks, at the very end: quit the game, then accept one
   more invite from Steam with the game closed, and say what happens.

## Afterwards
10. Quit the game. Before starting it again, send the host
    `Documents\My Games\XCOM2 War of the Chosen\XComGame\Logs\Launch.log`.
    The log includes your PC name and Windows user name; it stays on the
    host's PC and isn't published.
11. To remove the mod, delete `Mods\X2TacticalCoop`.

# M4: 0.8.4 checklist (PC + laptop on the LAN)

Plan: plans/m4-plan.md, "1.0 plan" (0.8.4). Everything new is a **guess**
until this run. ⏱ = note the clock time. 📷 = a screenshot (Win+Shift+S),
saved into `local\m4-logs\` with the name given.

New in 0.8.4:
- the release UI: the Co-op icon and its panel, "BY IP" names, and no
  MULTIPLAYER button;
- the **Verbose log** switch, on by default in this build;
- plain, grouped labels on CO-OP: FIXES;

  - a host network line (the ~210 KB/s cap);
  - a hack probe.

**No lag or hack fix yet.**
